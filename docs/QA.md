# 验收清单

每次提交或打包前执行本文件中的检查。

## 自动检查

```bash
npm test -- src/domain/calendar.test.ts src/domain/plan.test.ts
npm run build
env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u http_proxy -u https_proxy -u all_proxy npm run tauri -- build --debug --bundles app
```

## 手动检查

### 计划表单

- 可以新增只有标题的计划。
- 可以设置只有开始时间。
- 可以设置只有结束时间。
- 可以同时设置开始和结束时间。
- 可以清空开始时间和结束时间。
- 可以编辑已有计划。
- 删除计划前出现确认弹窗。
- 确认后可以删除计划。
- 可以标记完成。

### 矩阵视图

- 无时间计划进入未排期区域。
- 已过期计划进入已过期区域。
- 有时间的计划出现在矩阵主体。
- 时间更近的计划更靠近中心。
- 重叠计划在鼠标悬停时自动置顶。

### 日历视图

- 周/月切换正常。
- 只有开始时间的计划显示开始标记。
- 只有结束时间的计划显示截止标记。
- 同时有开始和结束时间的计划显示为长条。
- 跨周长条分段显示。
- 未排期计划显示在右侧区域。

### 列表视图

- 全部计划可见。
- 已过期计划优先显示。
- 编辑入口可用。
- 标记完成后状态刷新。
- 已归档计划可见。
- 已归档计划可以恢复为未开始。

### 复盘视图

- 顶部可以切换本周、近 7 天、近 30 天。
- 新增计划数按计划创建时间统计。
- 完成计划数按计划完成时间统计。
- 完成率按所选周期内新增计划中的已完成计划计算。
- 当前过期计划只统计正式计划，不包含 Daily 临时内容。
- 高重要计划统计使用重要度阈值。
- 四象限统计展示正式计划的总数、完成、过期和未完成数量。
- 明细区可以打开完成、过期、重要未排期的正式计划。
- 复盘视图不展示每日记录本和每日时间切片。

### 提醒通知

- App 打开时会检查正式计划提醒。
- 距离结束时间 30 分钟内的未完成、未归档正式计划会触发一次系统通知。
- 已过期的未完成、未归档正式计划会触发一次系统通知。
- 同一个计划、同一种提醒、同一个结束时间不会每分钟重复弹出。
- 已完成和已归档计划不会触发通知。
- 没有结束时间的计划不会触发通知。
- Daily 记录本和 Daily 时间切片不会触发通知。

### 后台运行与托盘

- 关闭主窗口后应用不退出，菜单栏出现托盘图标。
- 主窗口隐藏后，到期/过期提醒仍会在后台触发。
- 点击托盘图标可以重新显示主窗口。
- 托盘菜单包含显示主窗口、开机自启开关、退出。
- 选择退出后应用真正结束，不再提醒。
- 切换开机自启后，系统登录项中对应条目同步增减。
- 通过开机自启启动时，应用直接隐藏到托盘，不弹出主窗口。

### 每日视图

- 时间切片删除前出现确认弹窗。
- 确认后可以删除时间切片。

### 全局搜索

- 点击搜索按钮或按 ⌘K / Ctrl+K 可以打开搜索。
- 输入标题或描述关键字能匹配到对应计划。
- 多个关键字需要全部命中。
- 方向键上下可以切换选中项。
- 回车或点击结果会打开该计划的编辑弹窗。
- 关键字为空或无匹配时显示对应提示。

### 主题与深色模式

- 主题按钮在跟随系统、浅色、深色之间循环切换。
- 选择深色后界面整体切换为深色。
- 跟随系统时与 macOS 明暗外观一致，并随系统切换实时更新。
- 重新打开应用后主题选择保持不变。
