# 验收清单

每次提交或打包前执行本文件中的检查。

## 自动检查

```bash
npm test -- src/domain/calendar.test.ts src/domain/plan.test.ts
npm run build
env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u http_proxy -u https_proxy -u all_proxy npm run tauri -- build --debug --bundles app
```

## 手动检查

### 计划表单

- 可以新增只有标题的计划。
- 可以设置只有开始时间。
- 可以设置只有结束时间。
- 可以同时设置开始和结束时间。
- 可以清空开始时间和结束时间。
- 可以编辑已有计划。
- 删除计划前出现确认弹窗。
- 确认后可以删除计划。
- 可以标记完成。

### 矩阵视图

- 无时间计划进入未排期区域。
- 已过期计划进入已过期区域。
- 有时间的计划出现在矩阵主体。
- 时间更近的计划更靠近中心。
- 重叠计划在鼠标悬停时自动置顶。

### 日历视图

- 周/月切换正常。
- 只有开始时间的计划显示开始标记。
- 只有结束时间的计划显示截止标记。
- 同时有开始和结束时间的计划显示为长条。
- 跨周长条分段显示。
- 未排期计划显示在右侧区域。

### 列表视图

- 全部计划可见。
- 已过期计划优先显示。
- 编辑入口可用。
- 标记完成后状态刷新。
- 已归档计划可见。
- 已归档计划可以恢复为未开始。

### 复盘视图

- 顶部可以切换本周、近 7 天、近 30 天。
- 新增计划数按计划创建时间统计。
- 完成计划数按计划完成时间统计。
- 完成率按所选周期内新增计划中的已完成计划计算。
- 当前过期计划只统计正式计划，不包含 Daily 临时内容。
- 高重要计划统计使用重要度阈值。
- 四象限统计展示正式计划的总数、完成、过期和未完成数量。
- 明细区可以打开完成、过期、重要未排期的正式计划。
- 复盘视图不展示每日记录本和每日时间切片。

### 提醒通知

- App 打开时会检查正式计划提醒。
- 距离结束时间 30 分钟内的未完成、未归档正式计划会触发一次系统通知。
- 已过期的未完成、未归档正式计划会触发一次系统通知。
- 同一个计划、同一种提醒、同一个结束时间不会每分钟重复弹出。
- 已完成和已归档计划不会触发通知。
- 没有结束时间的计划不会触发通知。
- Daily 记录本和 Daily 时间切片不会触发通知。

### 每日视图

- 时间切片删除前出现确认弹窗。
- 确认后可以删除时间切片。
