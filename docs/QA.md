# 验收清单

每次提交或打包前执行本文件中的检查。

## 自动检查

```bash
npm test -- src/domain/calendar.test.ts src/domain/plan.test.ts
npm run build
env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u http_proxy -u https_proxy -u all_proxy npm run tauri -- build --debug --bundles app
```

## 手动检查

### 计划表单

- 可以新增只有标题的计划。
- 可以设置只有开始时间。
- 可以设置只有结束时间。
- 可以同时设置开始和结束时间。
- 可以清空开始时间和结束时间。
- 可以编辑已有计划。
- 删除计划前出现确认弹窗。
- 确认后可以删除计划。
- 可以标记完成。

### 矩阵视图

- 无时间计划进入未排期区域。
- 已过期计划进入已过期区域。
- 有时间的计划出现在矩阵主体。
- 时间更近的计划更靠近中心。
- 重叠计划在鼠标悬停时自动置顶。

### 日历视图

- 周/月切换正常。
- 只有开始时间的计划显示开始标记。
- 只有结束时间的计划显示截止标记。
- 同时有开始和结束时间的计划显示为长条。
- 跨周长条分段显示。
- 未排期计划显示在右侧区域。

### 列表视图

- 全部计划可见。
- 已过期计划优先显示。
- 编辑入口可用。
- 标记完成后状态刷新。
- 已归档计划可见。
- 已归档计划可以恢复为未开始。

### 每日视图

- 时间切片删除前出现确认弹窗。
- 确认后可以删除时间切片。
