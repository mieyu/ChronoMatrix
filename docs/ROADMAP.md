# 路线图

## v0.1 MVP

当前目标是形成可运行、可试用的桌面端基础版本。

- Tauri + React + TypeScript 桌面工程
- Tailwind CSS + shadcn/ui
- SQLite 本地存储
- 计划新增、编辑、删除、完成
- 矩阵视图
- 周/月日历视图
- 列表视图
- 未排期和已过期计划处理
- 核心业务规则单元测试

## v0.2 使用体验

- 更好的计划表单布局
- 日期快捷设置，例如今天、明天、本周五
- 矩阵卡片碰撞缓解和更稳定的视觉排布
- 日历视图支持切换月份和周
- 更清楚的已过期计划处理入口
- 空状态示例和首次使用引导

## v0.3 数据安全

- 数据导出
- 数据导入
- 手动备份 SQLite
- 自动备份策略
- 删除确认和归档恢复
- 数据库 migration 回归测试

## v0.4 发布准备

- 正式 app icon
- release 构建
- DMG 打包修复
- macOS 签名
- notarization 公证
- changelog
- 用户手册

## 暂不做

- 云同步
- 多用户协作
- 移动端
- Web 版
- AI 自动排程
