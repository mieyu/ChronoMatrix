# 产品说明

## 产品定位

时矩 ChronoMatrix 是一个 macOS 桌面端计划管理工具。它不是普通待办清单，而是用艾森豪威尔矩阵和日历视图帮助用户判断计划的优先级、时间压力和当前状态。

## 核心对象

每个计划至少包含：

- 标题
- 描述
- 重要程度，范围为 0-10
- 开始时间，可为空
- 结束时间，可为空
- 当前状态：未开始、进行中、已完成、已归档
- 派生状态：已过期

已过期状态不直接写入数据库，而是根据当前时间和结束时间动态计算。

## 状态规则

- 已完成计划保持已完成，即使结束时间已经过去。
- 已归档计划保持已归档。
- 未完成且结束时间早于当前时间时，派生为已过期。
- 开始时间早于或等于当前时间，且未完成、未归档、未过期时，派生为进行中。
- 其他情况保持未开始或数据库中的当前状态。

## 矩阵视图

矩阵视图是主视图。

- 重要：重要程度大于等于阈值，默认 6。
- 紧急：参考时间距离当前时间小于等于紧急窗口，默认 72 小时。
- 参考时间优先使用结束时间；没有结束时间时使用开始时间。
- 没有开始时间和结束时间的计划显示在未排期区域。
- 已过期计划不显示在矩阵主体，显示在已过期区域。
- 时间越接近当前时间，计划越靠近矩阵中心。
- 任务允许重叠；鼠标悬停或键盘聚焦的任务会自动置顶。

## 日历视图

日历视图支持周/月切换。

- 无开始、无结束：显示在未排期区域。
- 只有开始时间：在开始日期显示单日开始标记。
- 只有结束时间：在结束日期显示单日截止标记。
- 同时有开始和结束时间：显示为横跨日期的长条事件。
- 跨周事件会按周切片展示。

## 列表视图

列表视图用于完整扫描和管理全部计划。

- 展示标题、描述、重要度、状态、截止时间。
- 已过期计划优先显示。
- 支持编辑、标记完成和恢复已归档计划。
- 删除正式计划前需要二次确认。

## 复盘视图

复盘视图只统计正式计划，用于观察一段时间内的计划创建、完成、过期和矩阵分布。

- 支持本周、近 7 天、近 30 天三个周期。
- 周期统计包括新增计划数、完成计划数、完成率、当前过期计划数、高重要计划完成数、高重要计划过期数。
- 矩阵统计按重要/紧急四象限展示正式计划的总数、已完成、已过期和未完成数量。
- 明细区展示本周期完成的计划、当前过期计划、高重要但未排期计划。
- 复盘视图不读取、不展示每日记录本和每日时间切片；Daily 内容属于临时记录，不参与正式计划统计。

## 提醒通知

提醒通知只针对正式计划。

- App 打开时，每分钟检查一次正式计划。
- 已完成和已归档计划不提醒。
- 没有结束时间的计划不提醒。
- 距离结束时间 30 分钟内提醒一次。
- 计划过期后提醒一次。
- 提醒去重按计划 ID、提醒类型和结束时间记录；修改结束时间后可以再次提醒。
- 每轮最多发送 3 条系统通知，避免一次弹出过多通知。
- 每日记录本和每日时间切片属于 Daily 临时内容，不参与提醒通知。

## 后台运行与托盘

为了在不主动盯着窗口时也能收到提醒，应用支持常驻后台。

- 关闭主窗口不会退出应用，而是隐藏到 macOS 菜单栏托盘，提醒检查继续在后台运行。
- 点击托盘图标可以重新显示主窗口。
- 托盘菜单提供：显示主窗口、开机自启开关、退出。
- 只有在托盘菜单选择“退出”后，应用才真正结束，此时不再提醒。
- 开机自启开启后，登录系统会自动在后台启动应用并隐藏到托盘，无需手动打开即可提醒。
- 开机自启默认关闭，由用户在托盘菜单中自行开启或关闭。
- 后台提醒沿用相同的提醒规则与去重逻辑，只针对正式计划，不涉及 Daily 内容。

## 每日视图

每日视图以每日记录本为主，用于记录当天临时、琐碎、不适合进入正式计划表的事项。

- 每天按本地日期自动对应一本记录本。
- 今天打开时默认显示今天的记录。
- 明天会自动切换到新的空白记录本。
- 旧记录保存在历史中，可在每日视图内按日期查看。
- 每日视图支持记录本和时间切片两种模式；两者都属于同一天，但互相独立保存。
- 时间切片模式用 24 小时时间线表示一天；点击时间线两次即可记录开始和结束时间，不需要手动输入时间。
- 时间切片模式顶部显示当天横向总览线，用线段、刻度和标签概览已经规划好的时间结构。
- 删除时间切片前需要二次确认。
- 今日计划提醒保留在每日视图中，用于看到已过期、今天截止、今天开始、重要未排期的正式计划。

## 全局搜索

全局搜索用于在所有计划中快速定位一条记录。

- 顶部工具栏的搜索按钮可以打开搜索；快捷键为 ⌘K（Windows/Linux 为 Ctrl+K）。
- 按标题和描述进行匹配，大小写不敏感。
- 多个关键字之间是“且”关系，需要全部命中。
- 结果按已过期、进行中、未开始、已完成、已归档排序，同级再按重要度和标题排序。
- 支持方向键上下选择，回车打开对应计划的编辑弹窗，点击结果同样可以打开。
- 搜索覆盖全部正式计划，不包含 Daily 临时内容。

## 主题与深色模式

应用支持浅色、深色和跟随系统三种主题。

- 顶部工具栏的主题按钮在跟随系统、浅色、深色之间循环切换。
- 跟随系统会根据 macOS 的明暗外观自动应用，并在系统外观切换时实时更新。
- 主题选择保存在本地，下次打开自动恢复。

## 本地存储

桌面端使用 Tauri SQL 插件连接 SQLite。数据库连接名为：

```text
sqlite:chronomatrix.db
```

开发浏览器预览无法访问 Tauri runtime 时，使用 localStorage fallback，便于快速检查 UI。
