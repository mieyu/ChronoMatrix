# 产品说明

## 产品定位

时矩 ChronoMatrix 是一个 macOS 桌面端计划管理工具。它不是普通待办清单，而是用艾森豪威尔矩阵和日历视图帮助用户判断计划的优先级、时间压力和当前状态。

## 核心对象

每个计划至少包含：

- 标题
- 描述
- 重要程度，范围为 0-10
- 开始时间，可为空
- 结束时间，可为空
- 当前状态：未开始、进行中、已完成、已归档
- 派生状态：已过期

已过期状态不直接写入数据库，而是根据当前时间和结束时间动态计算。

## 状态规则

- 已完成计划保持已完成，即使结束时间已经过去。
- 已归档计划保持已归档。
- 未完成且结束时间早于当前时间时，派生为已过期。
- 开始时间早于或等于当前时间，且未完成、未归档、未过期时，派生为进行中。
- 其他情况保持未开始或数据库中的当前状态。

## 矩阵视图

矩阵视图是主视图。

- 重要：重要程度大于等于阈值，默认 6。
- 紧急：参考时间距离当前时间小于等于紧急窗口，默认 72 小时。
- 参考时间优先使用结束时间；没有结束时间时使用开始时间。
- 没有开始时间和结束时间的计划显示在未排期区域。
- 已过期计划不显示在矩阵主体，显示在已过期区域。
- 时间越接近当前时间，计划越靠近矩阵中心。
- 任务允许重叠；鼠标悬停或键盘聚焦的任务会自动置顶。

## 日历视图

日历视图支持周/月切换。

- 无开始、无结束：显示在未排期区域。
- 只有开始时间：在开始日期显示单日开始标记。
- 只有结束时间：在结束日期显示单日截止标记。
- 同时有开始和结束时间：显示为横跨日期的长条事件。
- 跨周事件会按周切片展示。

## 列表视图

列表视图用于完整扫描和管理全部计划。

- 展示标题、描述、重要度、状态、截止时间。
- 已过期计划优先显示。
- 支持编辑、标记完成和恢复已归档计划。
- 删除正式计划前需要二次确认。

## 每日视图

每日视图以每日记录本为主，用于记录当天临时、琐碎、不适合进入正式计划表的事项。

- 每天按本地日期自动对应一本记录本。
- 今天打开时默认显示今天的记录。
- 明天会自动切换到新的空白记录本。
- 旧记录保存在历史中，可在每日视图内按日期查看。
- 每日视图支持记录本和时间切片两种模式；两者都属于同一天，但互相独立保存。
- 时间切片模式用 24 小时时间线表示一天；点击时间线两次即可记录开始和结束时间，不需要手动输入时间。
- 时间切片模式顶部显示当天横向总览线，用线段、刻度和标签概览已经规划好的时间结构。
- 删除时间切片前需要二次确认。
- 今日计划提醒保留在每日视图中，用于看到已过期、今天截止、今天开始、重要未排期的正式计划。

## 本地存储

桌面端使用 Tauri SQL 插件连接 SQLite。数据库连接名为：

```text
sqlite:chronomatrix.db
```

开发浏览器预览无法访问 Tauri runtime 时，使用 localStorage fallback，便于快速检查 UI。
